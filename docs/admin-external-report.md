# 외부 주문용 깊은 사주풀이 PDF

최고 관리자(`super_admin`)로 로그인한 뒤 **관리자 → 운영 도구 → 외부 주문 PDF 생성**(`/admin/external-report`)을 연다.

1. 구매자 이름, 성별, 생년월일, 출생 시각을 입력한다. 생시를 모르면 해당 항목을 선택한다.
2. 음력은 평달만 지원한다. 윤달 생일은 정확한 양력 날짜로 변환해 입력한다. 출생 시각은 한국 표준시 기준이며 출생지 보정·자시 규칙은 기존 공통 입력 계산을 따른다.
3. **보고서 생성**을 누르고 생성이 끝날 때까지 기다린다. 기존 깊은 사주풀이의 AI 생성기를 사용하므로 API 호출 비용이 발생할 수 있다.
4. 이름·출생 정보와 본문을 확인하고 **PDF로 저장 · 인쇄**를 누른다. 인쇄 창에서 PDF 저장, A4, 기본 배율을 선택한다. 브라우저 자체 머리글·바닥글은 끈다.
5. 저장한 파일을 주문자에게 직접 발송한다. 다음 주문은 **다음 구매자 · 입력 초기화**로 시작한다.

생성 중 초기화하면 요청을 취소한다. 이미 끝난 AI 호출 비용까지 취소되는 것은 아니다. 입력을 수정하면 이전 보고서는 제거되며, 새로고침하면 입력과 결과가 사라진다. 자동 발송이나 주문 연동 기능은 포함하지 않는다.

## 보고서 구성

- 사주 구조와 성향 요약, 깊은 사주풀이 본문 전체.
- 대운별 심층 해석과 진입 전·진입·적응 구간의 실천 조언.
- 출생연도부터 100세까지 **101개 연도별 해석**. 각 연도는 배움·활동, 가족·관계, 생활·재물, 생활 리듬, 실천을 담는다.
- 연령대별 찾아보기와 실제 인쇄 페이지에 맞춘 목차.

나이는 출생연도를 0세로 한 연도 나이다. 100세는 분석 범위이며 수명 예측이 아니다. 대운의 마지막 구간은 실제 경계를 보존하므로 끝나는 나이가 100세를 넘을 수 있다. 연간 간지는 입춘 이후 대표 흐름을 사용한다. 생시 모름은 정오 기준 대운 추정임을 본문에 표시한다.

연도별 추가 해석은 실제 세운·대운·원국의 관계를 사용하는 결정론 계산이다. 매년 별도 AI 호출을 하지 않는다. AI 본편 생성 실패 시 관리자 화면에 **기본 계산 풀이로 생성**되었다는 안내를 표시하므로 발송 전에 확인한다.

일반 고객 PDF와 관리자 PDF는 같은 모델·문서 컴포넌트를 쓴다. 기존 고정 월별 점수 곡선은 생애 보고서에서 제외하고 보고서 목차로 교체했다. 일반 고객의 소유권·이용권 검사는 유지한다.

## 저장 및 권한

관리자 페이지와 POST API 모두 최고 관리자 권한을 검사한다. 구매자 계정·reading·이용권·프로필을 만들거나 변경하지 않는다. 입력은 URL·브라우저 저장소에 넣지 않고, AI 캐시와 생성 텔레메트리는 요청 메모리에만 둔다. 감사 로그에는 관리자, 무작위 보고서 번호, 생성 출처만 기록한다.

입력과 풀이의 일부는 기존 서비스와 동일하게 AI 생성 요청에 사용된다. 고객 PDF를 생성하는 일반 경로의 캐시·계측 동작은 변경하지 않는다. 중복 생성 방지는 서버 인스턴스 단위이며 분산된 전역 쿼터는 아니다.

## 로컬 검증

```bash
./scripts/with-node22.sh npm run typecheck
./scripts/with-node22.sh npm test
./scripts/with-node22.sh npm run test:spec
./scripts/with-node22.sh npm run test:pdf:layout
```

PDF 검증은 설치된 Playwright Chromium과 가상 정보만 사용하며 DB·AI를 호출하지 않는다. 결과는 Git에서 제외된 `.codex-run/pdf-verification/`에 저장한다. 기본·생시 모름 샘플은 각각 74쪽, 긴 본문 스트레스 샘플은 88쪽으로 검증했다. AI 본문 길이에 따라 실제 장수는 달라진다.
