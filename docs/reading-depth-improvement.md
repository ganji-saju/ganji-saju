# 사주풀이 깊이와 차별화 보강

2026-09-29. 현재 코드와 원문을 확인한 개발·편집 기준이다. 전문 명리인의 판정 검수 완료나 예측 정확도 인증을 뜻하지 않는다.

## 현재 부족한 지점과 반영 내용

| 확인한 문제 | 이번 반영 |
|---|---|
| 장별 AI에는 대표 십성·격국 이름·용신 한 줄만 주로 전달됨 | 월령을 확인할 월주, 자리별 천간 십성·지장간, 강약 근거, 격국 후보·투출·신뢰도, 용신 방법별 후보를 전달 |
| 강약이 없으면 중화로 채우고 신약을 차분함으로 바꿈 | 미산정은 미산정, 신강·신약은 원어 유지 |
| 관계·재물 입력 변환기가 별도로 복제됨 | 공통 변환기를 사용해 같은 근거가 모든 장에 전달되도록 수정 |
| 주요 장의 200~280자 지시가 근거 설명을 압축함 | 성향·역할·관계·재물·직업 장을 320~480자, 근거·양면·장면·선택 기준 구조로 조정 |
| 공감 예시가 실제 습관을 알고 있는 것처럼 표현됨 | 조건부 생활 장면과 본인이 비교할 기준으로 수정 |
| 기본 직업 풀이에서 식상·관성의 동시 존재만으로 설명이 갈림 | 기존 고전 규칙에 맞는 상관·정관·강약·재성/인성 조합, 신약·편관·인성 조합을 우선 설명 |
| 관계 풀이가 합·충의 존재만 알려줌 | 어느 지지의 어떤 글자 사이에 충·육합이 있는지 함께 명시 |
| 판정이 달라져도 같은 기둥이면 예전 장별 캐시가 재사용될 수 있음 | 지장간·강약·격국·용신 등 판정 근거도 캐시 키에 포함 |

장별 AI는 해당 기능이 활성화된 경우에 적용된다. 기본 직업·관계 풀이의 변경은 AI가 없어도 적용된다. 전체 평생 AI 풀이에도 공통 해석 원칙과 새 버전을 적용했다. 저장된 구매 결과·PDF를 일괄 수정하거나 운영 데이터를 재생성하지 않았다.

## 차별화할 풀이 순서

1. **명식의 중심**: 일간과 태어난 월령에서 출발한다. 오행 수가 많다는 설명으로 끝내지 않고 엔진이 어떤 계절·뿌리·도움과 소모 근거를 사용했는지 연결한다.
2. **서로 다른 해석 관점**: 격국은 무엇을 중심으로 읽는지, 억부는 일간의 강약을 어떻게 조절하는지, 조후는 계절 조건을 어떻게 보는지 구분한다. 서로 다른 용신 후보가 있으면 최종 채택과 참고 후보를 함께 설명한다.
3. **십성의 관계**: 정관과 편관, 정재와 편재, 식신과 상관을 뭉개지 않는다. 하나의 십성에서 성격·직업·재산을 곧바로 확정하지 않는다.
4. **성향의 양면**: 같은 특징이 어떤 환경에서는 강점이고 어떤 조건에서는 부담인지 비교한다. 좋고 나쁜 성격 목록으로 나누지 않는다.
5. **생활 분야별 질문**: 재물은 결과와 대가·관리 조건, 직업은 역할·권한·지원, 관계는 표현·기대·경계에 각각 답한다. 모든 장을 “기록하세요, 쉬세요”로 끝내지 않는다.
6. **시간의 변화**: 원국의 해석과 대운·세운의 계산을 구분한다. 계산된 기간과 관계가 있을 때만 변화 조건을 설명한다. 원국 고전 구절을 특정 해의 사건 예고로 옮기지 않는다.
7. **내 경험과의 비교**: “당신은 늘 그랬다” 대신 독자가 실제 경험을 대조할 질문을 남긴다. 입력한 상황이 있으면 배경으로 쓰되 없는 가족사·직업·상처를 채우지 않는다.

예를 들어 상관과 정관이 있는 명식에 “윗사람과 갈등합니다”라고 쓰는 대신, 확인된 강약과 다른 십성을 연결해 설명한다. 신강에 재성이 확인되는 경우 개선 제안을 비용·결과와 연결하는 조건을, 신약에 인성이 확인되는 경우 이해하고 준비할 지원을 비교하는 장면을 제시한다. 이는 전통 해석 관점을 생활 질문으로 옮긴 편집 예시이지 실제 성격 판정이나 원전 직역이 아니다.

## 정통성 검수에서 남은 일

현재 엔진은 강약을 가중 점수로 구분하고, 격국 후보와 조후·억부 후보를 자체 규칙으로 순위화한다. 이번 작업은 그 판단을 더 충실하게 전달한 것이며, 계산식 자체를 고전의 유일한 정답으로 검증한 작업은 아니다.

다음 보강은 문장 수보다 **판정 사례 검수**를 먼저 해야 한다.

| 우선 검수 대상 | 확인할 내용 | 통과 기준 |
|---|---|---|
| 월령·통근·투출·강약 | 절입 경계, 지장간의 작용, 강약 경계 사례 | 계산과 해석의 근거를 따로 제시하고 이견을 기록 |
| 격국·용신 | 조후와 억부가 다른 후보를 주는 사례, 낮은 신뢰도 | 주된 관점·보조 관점·판단을 보류한 조건을 설명 |
| 합충형해·제화 | 단순 동시 존재와 실제 작용 조건의 차이 | 합을 합화로, 동시 존재를 격 성립으로 자동 확대하지 않음 |
| 대운·세운 | 원국과 운의 관계, 교운 시점, 생시 미상 | 같은 사람의 시기 차이에 계산상 이유가 있음 |
| 종격·화격 등 예외 | 별도 성립·파격 조건과 학파 차이 | 검수 전에는 확정 문구나 새로운 분기 규칙을 추가하지 않음 |

검수용 명식은 개인정보 없는 합성 사례로 마련하고, 명리 검수자는 채택한 문헌·판본·적용 조건을 함께 기록한다. 사람마다 다른 문장이 나오는 비율만으로 정확성을 평가하지 않는다. 같은 계산 조건에는 일관된 설명이 나와야 하며, 달라진 조건은 설명 차이에 실제로 반영돼야 한다.

독자 품질 확인은 성인·미성년·생시 미상·관계/직업 미입력·낮은 격국 신뢰도·조후와 억부의 불일치 사례를 포함한다. 각 결과에서 “왜 이렇게 읽는지”, “내 상황을 지어내지 않는지”, “다른 장과 같은 조언을 반복하지 않는지”를 확인한다. 실시간 AI 생성·화면·PDF의 독자 평가와 전문 명리 검수는 별도로 남아 있다.

해석 캐시 및 오늘 운세 생성 버전을 갱신했다. 운영 배포 후 새로 생성되는 결과가 대상이며, 저장된 구매 결과·PDF의 일괄 재생성은 수행하지 않았다. 실제 AI 출력·화면/PDF 독자 검수와 전문 명리 검수는 위 남은 과제와 동일하다.

기존 원국 근거 보강 후에도 본편 프롬프트·호출 예산·출력 표시가 짧은 풀이에 맞춰져 있었다. 이번 변경은 새 판정법을 만들어내지 않고 근거를 충분히 설명할 공간을 확보한다.

- 공감의 기준은 확인된 계산 조합과 입력한 상황에서 나오는 구체적인 선택·갈등·반대 조건이다. 모르는 개인사·감정·과거 사건을 맞혔다고 단정하거나 보편적인 위로를 늘리지 않는다. 근거 부족은 분량으로 메우지 않는다.
- 캐시/생성 버전을 변경했다. AI 비활성·실패 시 기본 풀이 동작을 유지하며 운영 플래그를 임의로 켜거나 기존 구매 결과/저장 PDF를 일괄 재생성하지 않는다. 실제 생성 문장의 품질 평가는 배포 후 별도 검수 대상이다.
