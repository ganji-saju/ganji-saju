# 12지신 수호신 캐릭터 제작 스펙 (힉스필드용)

> 전면 개편 Phase 2 자산. 콘셉트: **"내 띠의 수호신이 읽어주는 사주"** — 생년 입력 시
> 자기 띠의 수호신이 전담 해설자로 배정된다. 비주얼 월드는 B안(한지·먹·인주) 확정(2026-08-24).

## 1. 스타일 바이블 (모든 프롬프트에 공통 적용)

| 항목 | 값 |
|---|---|
| 기법 | 한국 전통 민화·불화 풍 일러스트 + 현대적 캐릭터 디자인(과도한 유아용 SD 금지) |
| 배경 | 한지 질감 아이보리 `#F5EFE3` (투명 PNG 우선, 배경 포함본은 한지 텍스처) |
| 선 | 먹선(붓 터치가 살아있는 윤곽), 두께 일정 |
| 포인트 색 | 인주 `#B3372A` · 금박 `#A5813C` · 먹 `#1C1A17` (전체 채도 낮게, 단청 원색 남발 금지) |
| 인상 | 위엄 + 온화함 동시. 30~60대가 "장난 같다"고 느끼지 않을 격조 — 수호신(神獸)이지 마스코트가 아니다 |
| 복식 | 전통 도포·갑주·장신구를 동물 특성에 맞게. 각 캐릭터가 자기 지지(地支) 한자가 새겨진 인장/노리개를 소지 |
| 금지 | 서양 판타지 갑옷, 애니메 교복류, 네온색, 실사 합성 |

공통 프롬프트 접두(예시):
```
Korean traditional minhwa-style illustration, guardian deity character,
ink brush outlines on hanji paper texture (#F5EFE3), muted palette with
cinnabar red (#B3372A) and antique gold (#A5813C) accents, dignified yet
warm expression, full body, holding a seal stamp engraved with the hanja "X",
no text, no watermark
```

## 2. 제작 순서

### 1차 — 개편 런칭용 (~20장)
| 산출물 | 수량 | 용도 |
|---|---|---|
| **대표 수호신 1명** (권장: 호랑이 寅 — 한국 수호신 원형) 전신 | 1 | 새 홈 히어로 |
| 표정 변형 (온화 / 진지 / 미소) | 3 | 결과 챕터·대화 |
| 포즈 변형 (책을 읽는 / 붓을 든 / 인장을 찍는 / 손을 내미는) | 4 | 로딩·결제 완료·공유 카드·빈 화면 |
| **12지신 인장(도장) 문양** — 캐릭터 아님, 각 지지 한자+동물 실루엣의 원형 인장 | 12 | 카드 chip 업그레이드·수호신 배정 티저 |

### 2차 — 수호신 배정 오픈 (~36장)
12지신 전신 각 1 + 표정 2. **스타일 앵커: 1차 대표 캐릭터 이미지를 참조 이미지로 고정**하고
동물만 교체 — 이 방식이 12종 일관성의 핵심이다.

### 3차 — 확장 (수요 따라)
상품별 포즈(재물·연애·대운·택일), 시즌 한정(신년 등).

## 4. 파일 규격·배치 (개발 배선)

- 경로: `public/images/gangi/guardians/{zodiacKey}.png` (rat/ox/tiger/…/pig — `ZodiacKey` 와 동일 키)
  - 변형: `{zodiacKey}-{pose}.png` (pose: calm/serious/smile/reading/brush/stamp/greet)
  - 인장: `public/images/gangi/guardians/seals/{zodiacKey}.png`
- 원본 1024×1280(4:5) 이상 → 서빙용 avif/webp 파생은 기존 파이프라인 재사용
- 배정 로직: 생년 → 띠는 기존 유틸 재사용(`ZodiacChip` 이 쓰는 `GANGI_ZODIAC` 키와 동일).
  카드 `image` 필드는 Phase 0 에서 비워둔 상태 — 여기 guardians 경로로 재배선한다.

## 5. 수용 기준 (탈락 조건)

- [ ] 12종을 나란히 놓았을 때 같은 세계관으로 보인다(선 굵기·팔레트·비율 일치)
- [ ] 모바일 72px chip 크기로 축소해도 어떤 동물인지 식별된다
- [ ] 50~60대 테스트: "장난 같다" 반응이 나오면 표정·비율을 성숙 쪽으로 재생성
- [ ] 한자·문양이 뭉개지지 않는다(인장 12종은 벡터 트레이싱 후 사용 권장)
- [ ] 배경 투명 PNG 에 흰 테두리 잔상 없음
