# 개인정보처리방침 추가안 — 한 장짜리 랜딩 비회원 주문 (2026-10-21)

> 상태: **2026-10-21 사용자 승인 → DB privacy v1.0.5 로 발행 완료**(아래 표 기준, 문장은 PROGRESS 2026-10-21 기록 참고). 정책 본문은 번들 버전을 올리지 말고 **DB 새 버전 발행**으로 고친다(번들이 운영 DB 방침을 덮은 사고 이력). 반영 뒤 렌더된 `/privacy`로 확인한다.

## 추가할 항목

| 구분 | 내용 |
|---|---|
| 수집 경로 | 한 장짜리 랜딩(`/saju-report`) 비회원 주문서 |
| 수집 항목 | 이름, 성별, 생년월일(양력·음력), 태어난 시간대, 휴대폰 번호, 이메일, (선택) 남기실 말, (무통장) 현금영수증 신청 여부 |
| 이용 목적 | 사주풀이 제작, 결제·입금 확인, 접수 안내와 결과 링크 발송(문자·이메일), 환불 처리 |
| 보유 기간 | 결과 발송(또는 주문 종료) 후 1년. 기간이 지나면 위 항목과 풀이 원본을 지운다. 주문번호·상품·금액·결제 수단·날짜는 전자상거래법상 거래 기록으로 따로 보관한다 ⚠️ 보관 기간(5년 등) 확인 필요 |
| 처리 위탁 | 결제: 나이스페이먼츠 · 문자 발송: 솔라피 · 이메일 발송: Resend · 저장: Supabase (기존 위탁 목록에 없으면 추가) |
| AI 처리 | 풀이 본문은 사주 계산 결과를 바탕으로 AI(OpenAI)로 작성하며, 이름·생년월일 정보가 풀이 생성 요청에 포함된다(기존 회원 풀이와 같은 처리) ⚠️ 국외 이전 고지 문구는 기존 방침의 OpenAI 항목과 맞출 것 |

## 확인할 것
- 무통장 현금영수증 의무 발행 업종 여부 ⚠️ 검증필요
- 인공지능기본법상 생성형 AI 결과물 고지 범위 ⚠️ 검증필요 (랜딩·결과 화면에 "사주 계산과 AI로 작성, 상담사 확인" 문구와 `/ai-disclaimer` 링크를 넣어 둠)
