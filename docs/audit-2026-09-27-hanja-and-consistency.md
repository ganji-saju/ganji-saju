# 한자 노출 · 화면≠PDF 현황 (2026-09-27)

사용자 결정: **한자 전면 금지(명식 포함)** · **화면 = PDF = 다시 볼 때 같은 풀이**. 이 문서는 현재 어긋나는 곳의 목록이다.

## 1. 한자가 화면에 나오는 곳 (실측)

측정: 로컬 dev 서버, 로그인 없이 390px 화면의 실제 텍스트(`innerText`)에서 한자 글자 수. 사주 `1990-05-15 14:30 남`.

| 화면 | 한자 수 | 예 | 비고 |
|---|---|---|---|
| 사주 결과 `/saju/[slug]` | **31** | `四柱八字 · 네 기둥`, 명식 `癸未 庚辰 辛巳 庚午`, `午 · 말 수호신` | 무료 결과 — 가장 많이 보는 화면 |
| 깊은 풀이 `/saju/[slug]/deep` | **22** | `大運 · 대운 흐름`, 대운 간지 `壬午 癸未 甲申…` | |
| 프리미엄 `/saju/[slug]/premium` | 3 | `庚辰일주 · 말띠`, 장식 `月` | |
| 평생운세 PDF (오프라인 렌더) | **258** | 쪽 머리 `干支` ×93, 명식, 오행 `토(土)`, 십성 칩 | 결제 상품 |
| 평생운세 화면 패널 | (로그인 필요, 코드 확인) | 장식 글자 `月` 2곳 | |
| 연간 운세 패널(평생·신년 화면) | (코드 확인) | 장식 글자 `年`·`上`·`下` | |
| 신년운세 화면·PDF | **0** | — | #854 에서 명식까지 한글화 + 검사로 고정 |
| 오늘운세·대운·택일·띠·별자리·궁합·멤버십·무료허브·가이드 (로그인 전 화면) | 0 | — | 로그인 뒤 유료 본문은 아직 측정 못 함 |

⚠️ 검증필요: 로그인해야 보이는 **오늘운세 상세·평생운세 본문·AI 풀이 문장**은 이 방식으로 못 쟀다. AI 문장은 파서가 `koreanizeGanzi` 를 거치지만, 폴백(기본) 문장은 거치지 않는 경로가 있다(신년운세에서 실제로 새었던 경로).

코드 기준: 한자 글자가 들어 있는 코드 줄(주석 제외) 83개 파일·1,519줄. 대부분은 **계산용 내부 값**(천간·지지 키, 꿈 사전 등)이라 화면에 나가지 않는다 — 문제는 화면으로 나가는 **출력 경계**다.

### 왜 계속 새는가
한자→한글 변환(`koreanizeGanzi`)을 **화면마다 각자** 부른다. 새 화면이나 폴백 문장에서 부르는 걸 빠뜨리면 그대로 나간다. 이를 막는 자동 검사가 없었다(신년운세만 #854 에서 생김).

## 2. 화면과 PDF 풀이가 다른 곳

| 풀이 | PDF | 원인 | 상태 |
|---|---|---|---|
| 신년운세 | 있음 | 상담사 값 경로 차이 + 폴백 미저장 | **#852 에서 해결**(고정) |
| 평생운세(보관형 49,000원) | 있음 | **신년운세와 같은 구조** — 화면(`LifetimeReportPanel`)은 브라우저의 상담사 값을 보내고 다시 생성 버튼이 있다. PDF 는 서버가 프로필 값으로 고른다 → 다른 저장본 | **미해결** |
| 사주풀이(무료 결과·깊은 풀이) | 없음(평생 PDF 가 사실상 PDF판) | 평생 PDF 와 문장 출처가 다르다(결과 화면은 결정론 요약, PDF 는 AI 장문) | 확인 필요 — 어느 화면과 어느 PDF 를 비교하셨는지 |
| 오늘운세 | **없음** | — | 확인 필요 — "오늘운세 PDF" 가 무엇인지 |

## 3. "풀이가 매번 똑같고 문맥이 안 맞는다"
측정 전(다음 단계). 가설: AI 가 실패하거나 꺼져 있을 때 나가는 **기본 문장(템플릿)** 이 사람마다 거의 같고, 여러 템플릿 문장을 이어 붙여 문맥이 끊긴다(신년운세 폴백 캡처에서 같은 문장이 3번 반복된 것 실측).
측정 방법: 가짜 인물 N명으로 각 풀이를 뽑아 ① 폴백 비율 ② 사람 간 문장 겹침률 ③ 한 풀이 안 반복 문장 수를 센다.

## 4. 제안 순서
1. **한자 출력 경계 한 곳 + 렌더 검사**: 화면·PDF 출력 직전에 한글화를 한 번에 적용하고, 가짜 인물로 각 화면·PDF 를 렌더해 **한자 1글자라도 나오면 실패**하는 검사를 CI 에 건다(신년운세 검사를 확장).
2. **평생운세 화면=PDF 고정**: 신년운세 #852 와 같은 방식(상담사 고정·재생성 제거·폴백 포함 저장).
3. 풀이 반복·문맥 측정 → 개선안.
