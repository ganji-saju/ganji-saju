# 2027 신년운세 상품 설계 (2026-09-26)

## 0. 목적 · 합의 사항

새해를 시작하는 사람이 **2027년 한 해의 모든 운을 한 장에서 일목요연하게** 보고, PDF 로 보관하게 한다.

| 결정 | 내용 | 출처 |
|---|---|---|
| 상품 | 「2027 신년운세」 단일 메뉴, **19,900원**, PDF 다운로드 | 사용자 |
| 가족운 | 본인 사주 기준 가족 관계 풀이(가족 생년월일 입력 없음) | 사용자(질문2=1) |
| 기존 구매자 | 보관형 리포트 구매자도 **별도 구매** | 사용자(질문3=1) |
| 멤버십 | 프리미엄 멤버십 유효 시 **50% 할인(9,950원)** | 사용자(질문3=3) |

## 1. 접근: 기존 연간 운세 엔진 확장 (안 A)

이미 있는 것 — `buildYearlyReport`(결정론 계산) · `saju-yearly-service`/`saju-yearly-interpretation`(LLM 풀이·캐시·검증, prompt `saju-yearly-interpret-v7`) · `YearlyReportPanel` · 생애 PDF 인쇄 페이지(`/saju/[slug]/premium/print`, 브라우저 "PDF로 저장").

신규 엔진을 만들지 않는다(안 B: 두 엔진의 풀이 불일치 위험). 기존 패널만 떼어 파는 것(안 C)은 가족·학업·분기·PDF 가 없어 요구를 못 채운다.

## 2. 상품 · 결제

- 카탈로그 `new_year_2027`(`src/lib/payments/catalog.ts`): price 19900, `requiresSlug: true`, kind 는 단건 이용권 계열.
  - 이용권 scope = `new-year:<readingKey>:2027` — **만료 없음**(당일권과 다름). 사주 1개당 1행.
- 멤버십 50%: **`resolveChargeForUser`(coupon-charge.ts) 한 곳**에서 계산 — 체크아웃 표시와 prepare 가 같은 함수를 쓰므로 표시/청구 불일치가 없다.
  - 판정 시점 = prepare 시점의 프리미엄 멤버십 유효 여부(서버 조회, body 신뢰 금지). 금액은 `order.amount` 스냅샷(머니패스 원칙).
  - 할인 대상은 이 상품만(`new_year_2027`). 쿠폰과 중복 시 할인액이 큰 쪽 하나.
- 환불: 기존 단건과 동일 — 결제키 기준 `revokeEntitlementsOfPayment`(#819).
- 메뉴: 홈·메가 내비·`report-catalog.ts` 의 `yearly-2026` 카드를 「2027 신년운세」로 교체(href → 신규 구매 흐름).

## 3. 풀이 구성 (화면 = PDF 순서)

1. 표지·한눈에 — 2027 정미(丁未)년과 내 사주의 관계, 키워드 3, 한 줄 요약 *(무료 미리보기 범위)*
2. 총론 — 한 해 흐름, 상반기/하반기
3. 분야별 8종 — 기존 6(일·직업, 재물, 연애·결혼, 인간관계, 건강, 이동·변화) + **신규 `family`(가족운)·`study`(학업·시험운)**. 각 분야: 기회/주의/행동 + 강한 달
4. **분기별 흐름(신규)** — Q1~Q4 요약·분기 핵심 분야. 결정론 계산으로 월 momentum 을 묶고 LLM 이 요약
5. 월별 1~12월 — 기존(momentum·월간지·집중/주의/행동). 월 경계는 절기, 표기는 "2월(입춘~경칩 전)"처럼 양력 병기
6. **기대할 일 / 조심할 일(신규·핵심)** — 각 5개 안팎, 반드시 `{월, 분야, 문장}` 구조
7. 올해 행동 지침 체크리스트

풀이 원칙: "명확함" = 시기·분야를 구체적으로 짚는 것. 단정 예언·공포 표현 금지(기존 yearly 검증기 그대로), 건강운은 생활 습관 수준(진단·치료 권유 금지).

데이터 변경:
- `YearlyCategoryKey` 에 `family`·`study` 추가 → `YEARLY_CATEGORY_ORDER/LABEL`·`buildYearlyReport`·파서·검증기·패널 반영.
- `SajuYearlyAiInterpretation` 에 `quarterlyFlows[4]`, `expectations[]`, `cautions[]`(`{month, category, text}`) 추가.
- prompt version `v8` 로 올림 → 캐시 키가 바뀌어 기존 캐시와 섞이지 않는다.
- ⚠️ 검증필요: 2027 입춘·절기 날짜가 엔진 계산값과 천문 실제값이 일치하는지 대조.

## 4. 평생운세(보관형 리포트 49,000원) 반영

- 평생운세 안의 연간 패널은 같은 엔진 → 3장 변경이 **자동 반영**.
- 평생운세 본문 `SajuLifetimeAiSectionKey` 에 2장 추가:
  - `familyPattern` — 부모·배우자·자녀 관계에서 반복되는 역할·거리감·조율법
  - `studyPath` — 맞는 공부 방식, 배움이 열리는 대운 시기
- 화면(premium 페이지)·PDF(`pdf-report-model`/`ReportDocument`) 모두 반영. lifetime prompt version 올림.
- 기존 구매자: 다음 열람 시 새 버전으로 재생성(추가 결제 없음). ⚠️ LLM 비용 = 기존 구매자 수 × 1회 — 구현 전 구매자 수 조회(읽기 전용, 승인 후)로 금액 산정.

## 5. 화면 흐름

1. 메뉴 → 사주 입력(저장된 사주 선택 가능)
2. 미리보기: 1장만 공개, 나머지 블러-락. 가격 19,900원 / 멤버십이면 "9,950원(멤버십 50%)" 표시
3. 결제 → 생성 대기(진행 표시; 생성은 수십 초) → 캐시 저장, 재방문 즉시
4. 전체 보기 `/saju/[slug]/new-year/2027` + 보관함 등록
5. PDF: `/saju/[slug]/new-year/2027/print` — 이용권 확인 후 A4 문서(표지·목차·쪽번호), 브라우저 "PDF로 저장". 기존 `ReportPrintActions` 재사용
   - ⚠️ 검증필요: 카카오·인스타 인앱 브라우저에서 인쇄가 막히는지 — 기존 생애 PDF 처리 방식을 따르고, 없으면 "기본 브라우저에서 열기" 안내 추가

## 6. 오류 처리

- LLM 실패/검증 탈락: 기존 yearly 재시도·결정론 폴백 그대로. 결제 완료 후 생성 실패 시 이용권은 유지되고 재방문 시 재생성.
- 이용권 없이 print/전체 보기 직접 접근: 미리보기로 307.
- 멤버십 판정 실패(조회 오류): **정가로 계산**(할인 과다 지급보다 안전), 사용자에게 재시도 안내.
