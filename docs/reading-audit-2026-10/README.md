# 풀이 전면 보강 계획 (2026-10-10)

사용자 요청: "월별 풀이가 두 줄뿐 — 이렇게 짧으면 돈을 내지 않는다. 모든 풀이에서 빠져 있거나 부족한 부분을 보완·확장해 달라."
점검 원문: A(오늘운세·꿈·타로) · B(사주·평생·총평·오행) · C(궁합·올해/신년). 코드만 읽은 점검이며 시중 비교는 앱스토어 소개문 수준(⚠️ 실제 화면 미확인).

## 공통 원인
1. **길이를 처음부터 짧게 지시** — "모바일 운세 데이터·짧게·2문장·80~140자", 폴백은 1문장 88자 절단.
2. **사람마다 다른 근거가 빠져 있음** — 운(세운·월운·일진)의 십성, 원국 지지와의 합충, 용신 해당, 신살·대운이 AI 입력에 없음. 계산 함수는 대부분 이미 있다(연결만 하면 됨).
3. **사람과 무관한 고정표** — 월별 분야(MONTH_AREA_PLAN), 분야별 고정 문구, 관계 10종 문구표 → 같은 조건이면 모두 같은 문장.
4. **검증기 통째 폐기·재시도 사유 미주입** — 길게 쓰면 버려지고 고정 문구로 돌아간다.
