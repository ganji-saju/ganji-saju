# 기존 사주풀이 내용 개선 — 2026-09-18

## 이번 작업의 기준

평생·기본 사주·오늘의 운세에서 독자의 질문에 먼저 답하고, 계산된 사주 근거와 공감할 수 있는 생활 장면, 상황에 따른 선택 기준을 연결한다. 정확성은 계산·날짜·입력·본문 근거의 일치로 검증한다. 실제로 겪은 사건이나 미래 결과를 입력 없이 만들어 내지 않는다.

월별 풀이는 이번 범위에서 제외한다. 기존 0~100세의 101개 연도, 대운, PDF 워터마크와 저장 기록은 유지한다. 페이지 수나 신살 종류를 늘리는 것이 품질 목표가 아니다.

## 평생 리포트 목차와 질문

| 순서 | 장 | 답해야 하는 질문 |
| --- | --- | --- |
| 1 | 나를 이해하는 핵심 요약 | 어떤 강점이 반복되는가? 어떤 조건에서 부담으로 바뀌는가? 돈·일·관계에서 먼저 볼 기준은 무엇인가? |
| 2 | 타고난 성향과 선택 방식 | 편안할 때와 압박받을 때 무엇이 달라지는가? 원국의 어떤 조합을 그렇게 읽는가? |
| 3 | 돈을 벌고 남기는 방식 | 수입을 만드는 강점은? 돈이 남지 않을 때 점검할 패턴은? 공동 관리·큰 선택의 기준은? |
| 4 | 잘하는 일과 오래할 수 있는 일 | 어떤 역할·환경이 맞는가? 잘하지만 지치는 일은? 조직과 독립에서 각각 확인할 조건은? 인정은 어떻게 드러나는가? |
| 5 | 연애와 가까운 관계 | 가까워지는 속도와 표현은? 비슷한 갈등이 왜 반복될 수 있는가? 오래가는 관계에 필요한 조건은? |
| 6 | 부담과 회복의 방식 | 과하게 맡거나 소진될 때 살펴볼 패턴은? 생활 조건 안에서 무엇을 바꿔볼 수 있는가? |
| 7 | 현재와 다음 대운의 선택 | 이전 방식 중 무엇을 이어가고 조정할까? 장기 흐름과 해당 연도는 어떻게 연결되는가? |
| 8 | 생애 전체의 연도별 풀이 | 0~100세 각 연도의 초점·활동·관계·생활 기반·실천은 어떻게 다른가? |
| 참고 | 사주 구조와 용어 | 원국·오행·십성·격국·신살 중 실제 해석에 사용한 근거는 무엇인가? |

사주 구조 차트는 기존 디자인을 활용한다. 평생 점수처럼 읽히는 일일 운세 점수와 모든 고객에게 같은 강점·약점·조언은 새 보고서에서 제거한다. 핵심 질문형 본편을 연표보다 먼저 제공한다.

## 핵심 3개 장 원고 규격

### 돈

1. **어떤 방식으로 돈을 벌 때 강점이 드러날까?** 기존 `earningStyle`의 원국 근거와 조건별 장면을 설명한다.
2. **들어온 돈을 남기려면 무엇을 살펴봐야 할까?** `keepingStyle`과 `spendingMistakes`를 연결한다. 실제 소득·부채·소비 내역을 아는 것처럼 쓰지 않는다.
3. **함께 관리하거나 큰 결정을 할 때 기준은?** `operatingStyle`을 통해 책임·역할·확인할 조건을 설명한다. 특정 상품의 수익이나 투자 시점을 예고하지 않는다.

### 일

1. **어떤 일과 환경에서 실력이 드러날까?** `fitStructure`와 `endureVsShine`로 역할과 피로의 차이를 설명한다. 가능한 직업 이름을 무작정 나열하지 않는다.
2. **조직과 독립, 어떤 조건을 비교해야 할까?** `independenceStyle`을 통해 자율성·역할·협업 기반을 비교한다. 둘 다 무조건 좋다는 결론을 피한다.
3. **내 성과를 어떻게 보여주면 좋을까?** `recognitionStyle`을 통해 결과·과정·설명 방식과 평가 기준을 연결한다.

### 연애·관계

1. **가까워지는 속도와 마음을 표현하는 방식은?** `distanceStyle`과 `expressionStyle`의 관계를 설명한다.
2. **비슷한 갈등이 반복된다면 무엇을 살펴볼까?** `conflictTriggers`를 실제 일어났다는 진술 대신 조건부 장면으로 설명한다.
3. **오래 편안한 관계를 만들려면?** `longevityGuide`로 요청·경계·합의 기준을 제시한다. 미입력된 혼인 상태, 배우자 직업, 가족의 성격을 만들어 내지 않는다.

각 답변은 **결론 → 근거 → 가능한 생활 장면 → 상황별 선택 기준**으로 작성한다. 근거가 같은 경우 뜻이 이어질 수 있지만, 이름·연도·오행 단어만 교체한 문장을 개인화로 보지 않는다. 아동에게 성인의 돈·직장·연애 과제를 투영하지 않는다.

## 기본 사주와 오늘의 운세

- **기본 사주**: 원국에서 읽는 반복 성향과 조건을 간결한 질문별 답으로 제공한다. AI 총평과 실패 시 기본 풀이의 기준을 같게 유지한다. 균형 상태를 부족으로 단정하지 않고, 미산정 대운을 현재 대운처럼 설명하지 않는다.
- **오늘의 운세**: 원국 × 해당 날짜의 일진을 근거로 오늘의 질문에 답한다. 평생 성향을 매일 다른 사건처럼 말하지 않는다. 분야별 설명에는 답·근거·생활 장면·선택 기준을 연결하며 점수는 성공 확률로 표현하지 않는다.
- **시간 범위**: 평생은 타고난 방식과 긴 흐름, 기본은 자기 이해, 오늘은 해당 날짜의 판단과 행동에 집중한다. 월별 생성과 추가 일괄 생성은 하지 않는다.

## 샘플과 검증

샘플은 첨부된 실제 인물의 PDF를 복제하지 않고, 가상 입력을 기존 엔진으로 계산하여 새 생성기에서 만든다. 핵심 3장 모두 실제 계산 근거와 문장을 함께 확인한다. 같은 일간·다른 원국, 같은 원국·다른 날짜, 생시 미상, 대운 미산정, 미성년, 상황 미입력 사례를 포함한다.

기존 API·결제·저장 형식을 존중한다. 새 생성 결과와 기존 구매 기록의 재조회는 구분하고, 과거 snapshot을 자동 재생성하거나 추가 차감하지 않는다. 프롬프트·생성기 버전은 해당 캐시와 함께 갱신한다.
