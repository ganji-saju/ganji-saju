# 오늘운세 갭 검증 — 카나나(ChatGPT/카카오) vs 간지사주

> 대상: **1982-01-29 남성 진시(辰時)**, 오늘 = **2026-08-02**
> 방법: 배경 태스크의 코드 매핑을 재검증하고, **간지사주 결정론 엔진을 이 입력으로 실제 구동**해
> 실측 출력(무료 `buildTodayFortuneFreeResult` + 유료 `buildTodayFortunePremiumResult`)을 카나나 출력과 1:1 대조.
> 하네스: `calculateSajuDataV1(birth)` → 빌더(`now=2026-08-02T03:00:00Z`, LLM 플래그 둘 다 OFF=기본 프로덕션 상태).
> 프로덕션 DB 미접근, 코드/타입/템플릿·엔진 실행만.

---

## 0. 한 줄 결론

간지사주는 **원국 사실·오늘 일진·신살·용신·다층 간지(대운/세운/월운)를 카나나와 동등하거나 더 정확하게 "계산·탐지"** 한다.
갭은 **데이터가 없어서가 아니라, 그 계산 결과를 "십성/신살 명칭 + 인과"로 "서술"하지 않기 때문**이다.
즉 부족한 건 명리 엔진이 아니라 **서사(narration) 레이어**다.

## 1. 원국·오늘 일진 — 두 시스템의 사실 일치 (실측)

`calculateSajuDataV1` 실행 결과:

| 항목 | 간지사주 엔진(실측) | 카나나 서술 | 판정 |
|---|---|---|---|
| 일간 | **壬子 → 일간 壬水(임수)** | "겨울 임수 사주 주인공" | ✅ 일치 |
| 원국 4기둥 | 년 辛酉 · 월 辛丑 · 일 壬子 · 시 甲辰 | (명시 안 함) | — |
| 오행 편중 | **금 33.6%·수 27.3% 최다, 화 0%(missing)** | "원국에 금과 수가 워낙 많아" | ✅ 일치 |
| 강약 | 중화(66) | (냉정/열기 공존으로 우회 서술) | ≈ |
| 용신/기신 | **용신=화, 기신=금** (`luckyElement:"화"`, `unluckyElement:"금"`) | "화기운이 한기를 녹여주는 따뜻한 햇살" | ✅ 동일 판단 |
| 오늘 일진 천간 | **戊(무토)** → 壬 대비 **편관** | "일운 무토(편관)" | ✅ 일치 |
| 오늘 일진 지지 | **申(신금)** → 원국 子·辰과 **申子辰 삼합 수국** | (언급 없음) | 간지사주만 포착 |
| 월운 | **乙未** (입추 8/7 전이라 미월) | "월운 병신(丙申)" | ⚠️ 간지사주가 더 정확(丙申은 입추 후 시작) |
| 세운 | 丙午(2026) | (언급 없음) | 간지사주만 노출 |
| 신살 | **귀문관살(년+일)·양인살(일)·도화살·화개살·금여록·망신살(일진)** | "현침살과 **귀문관살**이 겹쳐" | ✅ 귀문관살 일치 / ❌ 현침살은 엔진에 미구현(17종 목록에 없음) |

**핵심**: 카나나가 근거로 든 명리 요소(임수·금수과다·화 용신·편관·귀문관살)를 **간지사주도 전부 내부적으로 산출**한다. 심지어 월운은 간지사주(乙未)가 카나나(丙申)보다 절기상 정확하다.

## 2. 생성 구조·사주 근거 깊이 매핑 (코드 재검증)

### 2.1 LLM은 사실상 없다 (기본 OFF)
- 무료: `OPENAI_TODAY_FORTUNE==='1'` (`src/server/ai/today-fortune/flag.ts`) — 미설정=결정론.
- 유료: `OPENAI_INTERPRET_TODAY_PREMIUM==='1'` (`today-premium-service.ts`) — 기본 OFF.
- 게다가 유료 LLM 프롬프트는 **명리어를 금지**: `FORBIDDEN_MYEONGRI = /기운|강약|격국|용신|대운|세운|월운|일진/`, `FORBIDDEN_CJK = /[㐀-鿿]/` (`today-premium-service.ts`). → **LLM을 켜도 카나나식 "화기운/월운/편관" 어휘는 구조적으로 못 씀.**

### 2.2 결정론 엔진의 사주 grounding은 깊다 (실측 확인)
- 일진 8축 점수 `calculateIljinScore` (`src/lib/today-fortune/iljin-score-engine.ts`): 이 사람 실측 breakdown =
  `cheongan:-7`(편관), `jiji:+23`(申子辰 삼합), `ohaeng:-10`(戊申=토금이 기신 금 보강), `unsung:+4`, `special:+10` → **총 70/100 "좋음"**.
- 신살 탐지 `detectComprehensiveSinsals` → chip 6종 노출(위 표).
- 용신/기신·오행 분포·삼합/충형해파·12운성·특수조합까지 반영.
- 유료 `evidenceLines`는 **대운/세운/월운 간지를 실제 노출**: `"큰 흐름 · 丁酉 / 丙午 / 乙未"`, `"용신 메모: 화 기운 · 보조 목·수"`.
  → 배경 매핑의 "월/년 간지는 삼재 탐지 전용" 은 **iljin 점수엔진에만** 해당. **유료 표면엔 다층 간지가 나온다**(단, 서술이 아니라 칩).

### 2.3 그런데 "서술"은 얇다 (실측 문장)
- 무료 `reasonSnippet`(화면 라벨 "사주 근거 한 줄") 실측:
  `"오전 정리 시간으로 봅니다. 흩어진 일을 정리하면 하루가 편해집니다…"` → **사주 용어 0개.**
- 무료 `oneLine.body`: `"겉으로는 나를 누르는 흐름이, 속에서는 나를 도와주는 흐름이 함께 도는 날…(무신)으로 본 흐름입니다"`
  → 편관(누르는)+인성/수국(돕는) 이중성을 **포착은 하나 명칭·인과 없음.** 오늘 일진만 `(무신)` 괄호로 노출.
- `iljinMessages`: 발동 케이스 `S12_삼합·S14_방합` (申子辰 수국)인데 화면 문구는 `"여럿이 함께 움직이는 흐름, 팀 프로젝트"` — **왜 삼합인지(오늘 申이 내 子·辰과 합) 설명 없음.**
- 문장이 조각 나열형: `"짧게라도 먼저 말해보세요. 머릿속 일을 목록으로 나눠보세요. 정답을 빨리…"` → 라이브러리 조합 특유의 **끊기는 문체**(카나나의 흐르는 산문과 대비).

## 3. 항목별 대조 — 카나나에 있고 간지사주에 없는 것

| 카나나 섹션 | 간지사주 대응 | 갭 |
|---|---|---|
| 한 줄 제목 + 체감점수(78) | `oneLine.headline` + `iljinScore`(70) | 점수·제목 **있음**. 단 제목이 "오전 정리 시간이라 말을 챙기면 좋은 날"로 밋밋 |
| 오늘의 모습(🧊🔥📝 이모지 요약) | 없음 | **이모지 무드 요약 없음** |
| 메뉴 추천(따뜻한 국물) | `luckyPackage.foods`(쓴맛·붉은 과일·단맛) | **있음, 오히려 더 구조적**(용신 화 기반 다항목) |
| **왜 이런 흐름이냐면**(일운 무토 편관 × 원국 × 월운 병신 인과) | `reasonSnippet`·`oneLine.body`·`evidenceLines` | 🔴 **최대 갭**: 데이터는 다 있는데 "일운 무토 편관이 들어와… 월운이 수기를 키워…" 같은 **다층 인과 서술이 없음** |
| **가장 크게 올라올 감정**(속이 타는 답답함, 자기의심) | 없음 | 🔴 **감정 예보 섹션 자체가 없음** |
| Do&Don'ts 챌린지(각 항목에 명리 근거 첨부) | 유료 `recommendedActions`/`avoidActions` | 있음. 단 "일운 편관이 책임을 요구하니…"식 **근거 태깅이 약함**(간지사주는 "책임과 원칙을 중요하게 보는 편이라…"로 순화) |
| **오늘의 귀인/주의 인물**(정인 귀인=멘토, 편재+편관=성급한 사람) | 없음(귀인은 신살/성씨초성으로 간접) | 🔴 **인물 서사(귀인/주의 인물) 없음** |
| 마무리 위로 문장 | `oneLine.body` 말미 | ≈ |

간지사주에 있고 카나나에 없는 것: **8영역 점수 그리드, 일진 8축 breakdown, 유료 시나리오 비교(바로 움직일 때 vs 흐름 보고), 유리/주의 시간대(09-11 유리·17-19 주의), 행운 12종 패키지.**

## 4. 갭 정리 (우선순위)

### 🔴 P1 — 다층 인과 서술 (가장 큰 체감 차이)
카나나의 강점은 **"일운 무토(편관) + 월운 병신 + 원국 금수과다"를 한 문단의 인과로 엮는 것**.
간지사주는 이 재료(편관·삼합수국·용신화·월운 乙未·세운 丙午)를 **전부 계산·보유**하지만 **칩/순화 문구로 흩어 놓음**.
→ 재료가 있으니 **조립(서술)만 하면 됨.** 신규 명리 계산 불필요.

### 🔴 P2 — 감정 예보 섹션 부재
"오늘 가장 크게 올라올 감정" 은 간지사주에 대응 섹션이 없음. 편관(압박)+귀문관살(예민)+화 결핍(조급)에서 **도출 가능한 재료는 이미 있음.**

### 🟡 P3 — 귀인/주의 인물 서사 부재
카나나는 십성(정인 귀인/편재 주의 인물)으로 인물상을 그림. 간지사주는 천을귀인·성씨초성으로 **간접만.**

### 🟡 P4 — 문체 품질(조각 나열 → 흐르는 산문)
라이브러리 조합 특유의 단문 이어붙이기. 무료 `body`·`reasonSnippet`에서 두드러짐.

### 🟢 P5 — 이모지 무드 요약(🧊🔥📝) — 표현상 소품, 저비용.

## 5. 권고 (무엇을 건드리면 되나)

1. **다층 인과 1문단 조립기 신설**(결정론). 입력은 이미 있는 값:
   일진 천간 십성(`calculateSipsung`) + 발동 삼합/충 + 용신/기신 오행 + 세운/월운 간지.
   출력은 "오늘 △△(십성)이 들어와, 원국의 ○○과 겹쳐 ~한 흐름" 1문단. `reasonSnippet`을 이걸로 교체.
   ⚠️ 명리어 노출 정책은 **결정론 경로엔 허용**(현재 `evidenceLines`가 이미 "용신 메모: 화 기운" 노출). 무료 표면 노출 수위는 별도 결정 필요(`docs/claude-specs/02-naming-policy.md` 우선).
2. **감정 예보 섹션 추가**: 편관/귀문관살/화결핍 → 감정 라벨 매핑 테이블(신살·십성 already detected).
3. **귀인/주의 인물**: 십성 기반 인물상 문구 라이브러리(정인=멘토/편관=압박형 등) — 신살 천을귀인과 연결.
4. LLM 경로는 **해법이 아님**: 무료 프롬프트는 십성/신살을 애초에 안 넘기고(`grounding.ts`), 유료는 명리어를 금지. 카나나식 서술을 원하면 **결정론 서사 조립기**가 정답(또는 명리어 허용 티어의 LLM 프롬프트 재설계).
